# Security policy

Please report security issues privately to the repository owner before opening a public issue. Include the affected release, Windows build, reproduction steps, and impact. Do not attach private conversations or account data.

The current live client adapter is disabled. The local CDP probe only checks a loopback endpoint after the user invokes it. Never expose a CDP port on the LAN or internet. Imported theme packages are treated as untrusted data and may contain only validated settings and local media.
