- WebView2 user data is stored under `%LOCALAPPDATA%\ThemeStudio\WebView2`, outside the portable application directory.
- Release build: `dotnet build ThemeStudio.sln -c Release --no-restore --verbosity minimal -m:1` passed with zero warnings and errors.
- Tests: 6/6 passed. Static verification passed for XML files, sample theme packages, and JSON resources.
- Self-contained `win-x64` publish stayed running for 10 seconds. The per-user installer also installed successfully, created its Start Menu shortcut, and the installed executable stayed running for 10 seconds.
- Local release outputs were generated under ignored `artifacts/`: `ThemeStudio-portable-win-x64.zip`, `ThemeStudio-Setup.exe`, and `SHA256SUMS.txt`. The unsigned setup is about 62 MB and portable ZIP about 91 MB.
